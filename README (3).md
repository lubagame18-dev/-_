# Части речи · 7 класс – общая доска

Интерактивная рабочая тетрадь: 8 занятий, шпаргалка, ключи для учителя.

Всё, что пишет ученица, учитель видит сразу, и наоборот: ответы, выбор в списках, выделенные слова, проверки. Вверху видно, кто сейчас на доске, на каком занятии и в каком задании. Поле, в котором печатает другой человек, обводится его цветом и подписывается его именем. Кнопка «Следить» сама переводит вас туда, где сейчас работает ученица.

Занятия и задания открываются в любом порядке. Задание можно сделать частично, посмотреть пару примеров и перейти дальше. Все результаты сохраняются.

## Шаг 1. Опубликовать на GitHub Pages

1. Создайте публичный репозиторий, например `chasti-rechi`.
2. **Add file → Upload files**: загрузите `index.html`.
3. **Settings → Pages**: выберите Source **Deploy from a branch**, ветку `main`, папку `/ (root)`, затем **Save**.
4. Через 1–2 минуты страница откроется по адресу `https://ВАШ-ЛОГИН.github.io/chasti-rechi/`.

Без шага 2 тетрадь уже работает, но в **локальном режиме**: ответы видны только на этом устройстве.

## Шаг 2. Включить прямой эфир (Firebase, бесплатно, около 5 минут)

1. Зайдите на https://console.firebase.google.com под своим Google-аккаунтом и нажмите **Создать проект**. Название любое, Google Analytics можно выключить.
2. В меню слева откройте **Build → Realtime Database → Create Database**:
   - регион выберите любой, например Belgium (europe-west1);
   - режим – **Start in test mode**.
3. Откройте вкладку **Rules** и вставьте это правило, затем нажмите **Publish**:

   ```json
   {
     "rules": {
       "boards": {
         "$room": { ".read": true, ".write": true }
       }
     }
   }
   ```

4. Откройте **Project settings** (шестерёнка) → **Your apps** и нажмите значок **</>** (Web app). Название любое, хостинг не нужен.
5. Firebase покажет блок `firebaseConfig`. Скопируйте из него значения `apiKey`, `authDomain`, `databaseURL`, `projectId`, `appId`.
   - Если `databaseURL` в блоке нет, возьмите адрес со страницы Realtime Database. Он выглядит так: `https://…firebasedatabase.app`.
6. В `index.html` найдите блок `window.FIREBASE_CONFIG` (в самом начале скриптов) и вставьте туда эти значения.
7. Загрузите обновлённый `index.html` на GitHub, заменив старый файл.

Вверху страницы появится зелёная метка **«В эфире»**.

## Как вести занятие

- **Вход учителя.** Нажмите **«Я учитель»** и введите код `2026`. Откроются ключи и панель доски. Код меняется в строке `const TEACHER_PIN`.
- **Ссылка для ученицы.** На панели нажмите **«Скопировать ссылку на доску»** и отправьте ссылку ученице. Ученица вписывает вверху своё имя и работает.
- **Отдельная доска для каждой ученицы.** Добавьте к адресу `?room=имя`, например `…/chasti-rechi/?room=masha`. У каждой комнаты свои ответы. Без параметра все попадают на общую доску `class`.
- **Остальные кнопки на панели:**
  - **«Скачать отчёт»** – текстовый файл со всеми ответами и отметками ✓ / ✗;
  - **«Очистить доску»** – стирает ответы у всех, кто на этой доске.

## Важно

- Правило из шага 2 открывает запись всем, у кого есть ссылка. Для занятий этого достаточно, но не храните на доске личные данные. Имена комнат лучше делать неочевидными: `?room=masha-7b-2026`.
- Код учителя только прячет ключи от ученицы. Это не настоящая защита.
- Если вставлять тетрадь через iframe на другой сайт, прямой эфир работает так же. Ссылку для ученицы всё равно надёжнее давать прямую.
